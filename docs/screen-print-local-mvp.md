# نسخة محلية أولية لمساعد مطابع السلك سكرين

**الحالة:** واجهة تجريبية تبقى محلية افتراضياً؛ أضيف دعم اختياري غير مهيأ لـSupabase للبريد/كلمة المرور والمزامنة اليدوية لسجلات الأرشيف فقط. ليست خدمة مستضافة أو منتجاً جاهزاً لاستقبال ملفات عامة. تفاصيل إعداد السحابة وحدودها في [screen-print-cloud-sync.md](screen-print-cloud-sync.md).

## التشغيل

من جذر المستودع بعد تثبيت `requirements.txt`:

```bash
streamlit run src/screen_print/app.py
```

لتغيير مكان سجل الأرشيف الوصفي محلياً:

```bash
SCREEN_PRINT_DATA_DIR="$HOME/.new-cela/screen_print" streamlit run src/screen_print/app.py
```

## ما تفعله النسخة

- إضافة/تحديث/حذف بطاقة فيلم والبحث في سجلات JSONL الوصفية؛ يُستبدل ملف JSONL ذرياً وتُكتب صلاحيات الملف `0600` على POSIX. لا توجد نسخة احتياطية مفعّلة.
- فحص أولي لصورة PNG/JPEG/TIFF واحدة في مجلد مؤقت، مع سقف خادمي للرفع وسقف تطبيقي للحجم والأبعاد؛ لا تُحفظ الصورة في الأرشيف، ويُزال مسار النسخة المؤقتة بعد الفحص. قد تبقى بايتات الرفع في ذاكرة جلسة Streamlit حتى انتهاء الجلسة، ولا يوجد ضمان للمحو الآمن من وسيط التخزين.
- تقدير مبدئي للشبلونات والحبر والتكلفة وفق القيم الافتراضية التي يوفرها محرك `src/screen_print/engine.py`.
- **صياغة prompts للنقوش المتكررة وتخصيصها حسب الشريحة/الألوان، وموجز نصي للموك أب** يحافظ على العمل الفني المدخل؛ هذه نصوص قابلة للنسخ فقط ولا تستدعي مولّد صور أو عارضاً افتراضياً.
- **فحص دقة الصورة بالنسبة إلى المقاس المادي وDPI** وإظهار قناة الشفافية؛ لا يرفع الدقة بالذكاء الاصطناعي ولا يفصل ألوان spot أو يزيل الخلفية.
- **إحصاء محلي لملاحظات الاتجاهات التي يدخلها المستخدم يدوياً**؛ لا يجمع بيانات اجتماعية أو يتنبأ بالطلب، ولا يتصل بمتجر لتخصيص التوصيات.

## ما لا تفعله وما لا ينبغي ادعاؤه

- دعم تسجيل الدخول/المزامنة السحابية اختياري ويتطلب مشروع Supabase مملوكاً وإعداد RLS؛ لم يُختبر على مشروع حي ولا يساوي مصادقة إنتاج معتمدة. لا توجد إدارة متعددة المستأجرين/الأدوار أو تخزين سحابي للصور. في وضع عدم تسجيل الدخول تبقى البيانات محلية.
- الأرشيف يحفظ **البيانات الوصفية فقط** على الجهاز؛ لا يخزن نسخاً أصلية من أفلام الطباعة ولا يثبت نسخاً احتياطية أو تشفيراً عند السكون.
- فحص الصورة heuristic محدود، وليس اعتماداً فنياً أو ضماناً لسلامة التعريض أو جودة الطباعة أو فصل الألوان. يجب مراجعة كل نتيجة بشرياً.
- تقدير التكلفة يستخدم افتراضات محلية قابلة للتغيير؛ ليس عرض سعر. راجع أسعار الخامات والأجور والهدر والضرائب قبل استعماله.
- لا ترفع ملفات عملاء حقيقية إلى معاينة مشتركة أو بيئة عامة. هذه النسخة لا تملك عزل مستخدمين أو مسار حذف شامل أو مراقبة تشغيلية.

## التحقق

تغطي اختبارات الوحدة محرك الأرشيف والحساب والفحص، وحدود الرفع المؤقت (الحجم، الأبعاد، نوع الصورة، الملفات متعددة الإطارات، وحذف الملف المؤقت بعد انتهاء الفحص). لا تغني هذه الاختبارات عن مصفوفة أفلام واقعية من برامج المطابع أو اختبار تخزين إنتاجي.

# سجل أنشطة معالجة البيانات — مسودة داخلية للتعبئة والتحقق

**الحالة: غير مكتمل، غير صالح للنشر أو لإثبات الامتثال.**
**آخر فحص للكود المحلي: 2026-10-24.** هذا السجل يغطي ما أمكن فحصه في checkout `new-cela` فقط؛ لا يغطي خدمات أو مستودعات أخرى أو إعدادات النشر غير الموجودة هنا. راجعه مختص قانوني مصري قبل اعتماد الأساس القانوني أو النقل عبر الحدود.

## قاعدة الإثبات

- لا يُسجّل أي ادعاء تشغيلي كحقيقة إلا مع **دليل قابل للمراجعة**: ملف/دالة/اختبار/إعداد نشر أو عقد مزوّد.
- `غير مثبت` لا يعني أن المعالجة غير موجودة؛ يعني أن هذا المستودع لا يثبتها.
- لا تُنشر أسماء مزوّدي الخدمة أو البلدان أو مدد الاحتفاظ بالتخمين.
- لا تتحول هذه المسودة إلى سياسة خصوصية قبل ملء الحقول والتحقق من التطابق مع النظام المنشور.

## عناصر يجب استكمالها من التشغيل الفعلي

- اسم المتحكّم/المالك ووسيلة اتصال الخصوصية ومسؤول تنفيذ الطلبات.
- جرد كل المستودعات والخدمات واللغات ونقاط الدخول، بما فيها تطبيقات الويب وMCP وwebhooks والبريد والاستيراد من URL ومزامنة Drive.
- إعدادات الإنتاج: الاستضافة، قاعدة البيانات، object storage، cache، logging، النسخ، المناطق الجغرافية، والصلاحيات.
- مخطط بيانات الطلبات المرسلة إلى كل مزود AI أو بريد/دعم، وسياسات الاحتفاظ والحذف التعاقدية لكل مزود.
- مدد الاحتفاظ الفعلية وإجراء حذف/اطلاع قابل للتنفيذ والاختبار، بما فيه corpus وذاكرة الوكلاء والكاش والسجلات والنسخ الاحتياطية.
- هل توجد معالجة/نقل خارج مصر؟ البلدان والأساس/التصريح المناسب يحدده مختص قانوني، لا هذا السجل.
- الدفع: لا تُدرج معاملة أو مزوداً حتى يظهر التكامل الفعلي وتُراجع webhooks والتوقيع وidempotency والمبلغ/العملة من الخادم.

## إجراء تحديث السجل

لكل صف: أرفق دليلاً محدداً، حدّث `last_verified` و`owner`، وافصل بين **الموجود حالياً** و**المخطط**. بعد أي تغيير في الكود أو المزوّد أو إعداد المنطقة، أعد التحقق قبل تحديث سياسة الخصوصية. أي صف بلا دليل يبقى `غير مثبت` ولا يتحول إلى وعد للمستخدم.

# استراتيجية النيش العمودي ومنافسة المنصات العامة (Manus نموذجاً) — مرجع حاكم لـ `new-cela`

> **الحكم التنفيذي:** منافسة مباشرة كمنصة Agent عامة (مثل Manus) ← **غير واقعية**.
> منافسة في **نيش عمودي محدد بالعربية + امتثال محلي + دفع بالجنيه المصري** ← **ممكنة ومربحة**.
>
> تاريخ التحقق الفعلي من أرقام السوق: **2026-10-24** (Africa/Cairo).
> الوحدة البرمجية المنفِّذة: [`src/core/niche_strategy.py`](../src/core/niche_strategy.py) · العرض عبر CLI: `python -m src.main --niches`.

## ⏱️ 4. مقياس القرار بعد 90 يوماً (البند 7 — `evaluate_90_day_gate`)

بعد 90 يوماً من إطلاق النيش الأول مع خدمة الإعداد المُدارة (Managed Setup)، تُشغَّل دالة `evaluate_90_day_gate` في [`src/core/niche_strategy.py`](../src/core/niche_strategy.py) على الأرقام الفعلية لإصدار القرار الحاسم:

1. **الشرط الأول (الطلب الحقيقي):** هل يدفع **10 مستخدمين فعلياً**؟ (`paying_customers >= 10`)
2. **الشرط الثاني (الموثوقية المهنية):** هل نسبة نجاح المهام في النيش **فوق 85–90%**؟ (`task_success_rate >= 0.85`، ومثالي `>= 0.90`)
3. **الشرط الثالث (ربحية الوحدة):** هل **هامش الربح لكل مستخدم موجب** بالجنيه المصري؟ (`margin_per_user_egp > 0`)

### مصفوفة القرار الآلي (`NinetyDayDecision`):
- **`EXPAND` (وسّع):** إذا تحققت الشروط الثلاثة معاً ← وسّع المبيعات في نفس النيش وأضف سير العمل التالي.
- **`FIX_UNIT_ECONOMICS`:** إذا كان الهامش سالباً أو صفراً ← اضبط توجيه النماذج (`LLMRouter`) أو سقف الحصص قبل إضافة عملاء جدد.
- **`FIX_WORKFLOW_RELIABILITY`:** إذا كانت نسبة النجاح أقل من 85% ← جمّد التسويق وحسّن الـ 1–2 مهام الأساسية واختبارات القبول (`Evals`).
- **`PIVOT_NICHE_KEEP_TOOLS` (غيّر النيش لا الأدوات!):** إذا كانت الموثوقية `>= 85%` والهامش موجباً لكن عدد الدافعين `< 10` بعد 90 يوماً ← **احتفظ بكل البنية الهندسية والأدوات الحالية كما هي، وانتقل فوراً إلى النيش التالي في القائمة!**
